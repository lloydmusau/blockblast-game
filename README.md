## 🚀 About the Project
**Block Blast** is a grid-based puzzle game where players strategically place various geometric block shapes onto a board to clear rows and columns, aiming for the highest possible score. This project was built to demonstrate advanced Java GUI design, event handling, and game state logic using **Java Swing** and **AWT**.

---

## ✨ Key Features
* **Interactive GUI Window:** Built with custom Java Swing components and layout managers (`JFrame`, `JPanel`, custom grid rendering).
* **Dynamic Piece Placement:** Smooth click-and-drag or click-to-place mechanics for handling custom geometric block shapes.
* **Score & Progress Tracking:** Real-time updating scoreboard that tracks player points and checks for game-over conditions.
* **Clean OOP Architecture:** Separated into distinct classes handling game logic, piece rendering, and user interface controls.

---

## 🛠️ Tech Stack & Concepts Used
* **Language:** Java
* **GUI Framework:** Java Swing & AWT (`javax.swing.*`, `java.awt.*`)
* **Concepts:** 
  * Object-Oriented Programming (OOP)
  * Event Listeners & Action Handling
  * 2D Arrays for Grid State Management
